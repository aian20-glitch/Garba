# GARBA — MVP Starter

Это стартовая кодовая база для онлайн-игры «Гарба».

## Что уже заложено

- Комнаты на 4–7 игроков.
- Стартовый баланс 10 000 монет.
- Вход в кон по 100 монет.
- Колоды для 4 / 5 / 6 / 7 игроков.
- Допустимые козырные масти по количеству игроков.
- Проверка обязательной масти / козыря.
- Определение победителя одного хода.
- Проверка комбинации ГАРБА = Q + K + A козырной масти.
- Определение первого раздающего по первому Тузу.
- Пауза при отключении игрока на 5 минут.
- Закрытие комнаты после таймаута.
- Каркас мобильного приложения Flutter.
- В интерфейсе уже зафиксировано, что монеты виртуальные и без денежного эквивалента.

## Важные зафиксированные правила

### РАЗ / ДВА / ИЗЖОГА
- РАЗ — открытая козырная масть.
- ДВА — другая допустимая козырная масть.
- ИЗЖОГА — масть, которая не может стать козырной.
- РАЗ выше ДВА.

### Главный игрок
- Играет один против остальных.
- Для победы должен взять минимум 3 карты/хода из 5.
- Если баланса не хватает для покрытия возможного проигрыша, главным стать нельзя.

### ГАРБА
Q + K + A козырной масти.

### Туз
- Первый выбор — вслепую, на ×1.
- Решения «оставить / отдать» у владельца нет: после раздачи первой карты любой
  по очереди может забрать туза, предложив ×2, дальше ×3, ×4, ×5.
  Чтобы вернуть туза, прежний владелец сам предлагает множитель выше.
- Подробно — RULES.md, раздел 7.

### Король и Дама
- Всем сначала раздаётся по 1 карте.
- Все смотрят карту.
- Забрать можно начиная с риска ×2.
- Далее ×3, ×4, ×5.

### 6
- Всем по 1 карте.
- Кто первым по очереди забрал — тот главный.
- Перехвата после этого нет.
- Забравший 6 ходит первым.

### 10
- Всем по 1 карте.
- Кто первым по очереди забрал — тот главный.
- Перехвата после этого нет.
- Забравший 10 ходит последним в первом ходе.

### Сыгранные карты
- Все сыгранные карты остаются видны всем игрокам.
- У владельца сыгранные карты тоже остаются видимыми, но серыми/неактивными.

### Чат
- Во время игры текстового чата нет.
- После игры доступны только реакции/смайлики.

### Отключение
- Пауза 5 минут.
- Если игрок не вернулся, комнату продолжать нельзя.
- Кон делится между оставшимися игроками.
- Остаток монет должен получить игрок, который больше всего проиграл в этой комнате.
  В текущем коде это помечено как TODO и временно используется игрок с наименьшим балансом.

## Запуск backend

```bash
cd backend
npm install
npm run dev
```

Проверка:

```bash
curl http://localhost:3000/health
```

## Запуск Flutter

Нужен установленный Flutter SDK.

```bash
cd mobile
flutter pub get
flutter run
```
