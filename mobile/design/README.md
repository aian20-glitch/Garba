# Иконка ГАРБА

Чёрно-золотой знак с тремя картами и надписью ГАРБА.

- `app-icon-v3.png` — актуальный мастер иконки (23.09.2026): тот же рисунок, что v2, но без
  белого фона вокруг — квадрат залит до краёв, углы скругляет сама система. Из него собраны
  все размеры iOS и Android; у переднего слоя адаптивной иконки Android — поля 14 % под маску.
- `app-icon-v2.png` — прежний мастер, с белым фоном (давал белую обводку на iPhone).

Старые SVG сохранены как архив предыдущей версии иконки.

Перерисовать PNG: открыть SVG в Chrome без окна
(`--headless=new --screenshot --window-size=1024,1024 --default-background-color=00000000`)
и уменьшить `sips -z <px> <px>` до размеров из `mipmap-*` и `AppIcon.appiconset`.
