без рекламы, без чата). Изменилось приложение — сначала поправить здесь.

Что на самом деле собирается: игровое имя (ник), код игрока / id аккаунта, игровые данные

## App Store Connect

### App Privacy («Конфиденциальность приложения»)
- Собираете ли вы данные? — **Да**.
- Типы данных:
  - **Contact Info → Name** — игровое имя. Связано с пользователем: да. Отслеживание: нет.
    Цель: App Functionality.
  - **Identifiers → User ID** — код игрока. Связано: да. Отслеживание: нет. Цель: App Functionality.
  - **User Content → Gameplay Content** — ход игры, статистика. Связано: да. Отслеживание: нет.
    Цель: App Functionality.
- Всё остальное — не собираем. То же записано в `mobile/ios/Runner/PrivacyInfo.xcprivacy`.

### Возрастной рейтинг (Age Rating)
- Simulated Gambling (симуляция азартных игр) — **Frequent/Intense (часто)** → 18+.
- Gambling (азартные игры на реальные деньги / контесты) — **No**.
- Насилие, секс, нагота, алкоголь, наркотики, ужасы, ругательства — **None**.
- Unrestricted Web Access — **No**.
- User-Generated Content / общение между игроками — только смайлики из готового набора и
  игровые имена. Если спросят про messaging/chat — **No** (текстового чата нет).
- Итог: **18+**.

### Шифрование (Export Compliance)
- В `Info.plist` уже стоит `ITSAppUsesNonExemptEncryption = NO` — вопрос не задаётся.
  (Только https — это освобождённое шифрование.)

### Вход для проверяющего Apple (App Review Information)
- Логин не нужен: аккаунт создаётся по имени при первом запуске → **Sign-in required: No**.
- Заметка для проверяющего:
  ```
  Enter any name on the first screen — an account is created instantly, no login.
  To play right away with computer players:
  1. Tap "СОЗДАТЬ КОМНАТУ" (Create room), keep the default settings and tap
     "СОЗДАТЬ КОМНАТУ" at the bottom.
  2. In the room, tap "ДОБАВИТЬ БОТОВ · ТРЕНИРОВКА" (Add bots · Practice) — the free
     seats are filled with bots at once.
  3. Tap "ГОТОВ" (Ready). The game starts; the bots play by themselves.
  The rules are in "ПРАВИЛА" on the main screen. In-game coins are virtual only: they
  cannot be bought, sold or exchanged for money. No in-app purchases, no ads.
  ```
  Боты сервера — кнопка в лобби (27.09.2026): проверяющему никого ждать и писать не нужно.

### Прочее
- Content Rights: приложение не использует чужой контент — **No**.
- Аккаунт удаляется в самом приложении (Профиль → «Удалить аккаунт») — требование Apple 5.1.1(v)
  выполнено.

## Google Play Console

### Data safety («Безопасность данных»)
- Собирает ли приложение данные? — **Да**. Передаёт третьим лицам? — **Нет**.
- Шифрование при передаче — **Да** (https).
- Можно ли запросить удаление данных? — **Да**, ссылка: https://garbagame.kz/support
- Типы:
  - **Personal info → Name** — собирается, не передаётся, обязательно, цель: App functionality,
    Account management.
  - **Personal info → User IDs** — то же.
  - **App activity → Other actions (игровые действия)** — собирается, цель: App functionality.
- Остальное (местоположение, контакты, фото, финансы, устройство и т.д.) — не собирается.

### Удаление аккаунта (Account deletion)
- Приложение позволяет создать аккаунт — **Да**.
- Ссылка на удаление: **https://garbagame.kz/support** (раздел «Как удалить аккаунт»).

### Анкета IARC (возрастной рейтинг)
- Категория — **Игра**.
- Насилие, страх, секс, ругательства, наркотики — **Нет**.
- Азартные игры: симуляция азартных игр (игровые монеты, карточная игра) — **Да**;
  можно ли выиграть реальные деньги или ценности — **Нет**; покупка монет — **Нет**.
- Общение между пользователями — **Да** (игроки видят имена друг друга и смайлики из набора);
  обмен личной информацией — **Нет**; текстовый чат — **Нет**.
- Покупки в приложении — **Нет**. Реклама — **Нет**.
- Покупка цифровых товаров — **Нет**.

### Целевая аудитория (Target audience)
- Возраст: **18 и старше**. Для детей не предназначено.

### Прочее
- Реклама — **Нет**.
- Государственное приложение — **Нет**. Финансовые функции — **Нет**. Здоровье — **Нет**.
- Новости — **Нет**.
- Доступ для проверки (App access) — **Всё доступно без входа** (аккаунт по имени).
- Закрытое тестирование: для личного аккаунта — **12 тестировщиков, 14 дней подряд** до
  подачи на публикацию. Почты тестировщиков — список в Play Console → Testing → Closed testing.
