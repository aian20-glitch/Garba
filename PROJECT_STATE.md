# GARBA — состояние на 20.09.2026

## Готово
- Flutter-клиент Android/iPhone; Node/TypeScript + Express/Socket.IO, SQLite; скрипты VPS в deploy/.
- Реализованы комнаты на 4–7 игроков, торги, спецкарты, розыгрыш, расчёты, восстановление комнат, аккаунты, друзья, бонусы, рейтинг и аватары. Правила — RULES.md; решения принимает сервер.
- Проверки: backend — 409; интеграционные Socket.IO и перезапуск сервера прошли; flutter analyze — без замечаний.
- iOS: bundle kz.garba.app, iOS 15+, только iPhone/портрет, плагины через SwiftPM, фото и garba:// настроены. Симулятор iOS 27 установлен; debug-сборка успешна.
- Исправлен экран входа: с клавиатурой форма прокручивается. Тест на 375×667 воспроизводил overflow 93 px до исправления и проходит после.

## Сейчас
- iPhone 17e / iOS 27: интеграционный тест прошёл основные экраны, вход по приглашению, старт и завершение партий на 4 и 7 игроков без ошибок Flutter. Ходы в тесте отправлялись через API, состояние отображалось в приложении.
- Для владельца запущена обычная lib/main.dart, аккаунт «Игрок iPhone», комната 28950 (5 мест, взнос 100). Айдар, Дана, Ержан, Асель подключены в фоне; старт — кнопкой «НАЧАТЬ ИГРУ». Сервер localhost:3000.
- Добавлены integration_test (из Flutter SDK), integration_test/ios_smoke_test.dart и tool/prepare_manual.dart для локальной подготовки ручной игры. Тест создаёт отдельные аккаунты на выбранном backend; запускать на тестовой базе.

## Следующий шаг
- Ручная игра владельца; затем проверить длительное сворачивание во время партии, выбор/загрузку фото и системное «Поделиться». Эти сценарии ещё не подтверждены; автоматическое управление системными окнами недоступно без разрешения Accessibility.
- Перезапуск обычного приложения сохраняет аккаунт. Реальная iOS-ссылка garba://room/28950 распознана системой: сейчас показано «Открыть в приложении ГАРБА?». Владельцу нажать «Открыть», затем «НАЧАТЬ ИГРУ»; также доступно «Вернуться в комнату» на главном экране.
- Затем физический iPhone и release-сборка: нужен доступный сервер через API_BASE и настройка подписи.

## Важные баги и решения
- README устарел: проект уже не стартовый каркас. Старые записи CLAUDE.md об отсутствии симулятора неактуальны.
- Без API_BASE iOS обращается к localhost:3000 — это подходит симулятору, но не серверу на Mac при запуске на физическом iPhone.
- Нет восстановления аккаунта после потери токена; часть HTTP-ошибок скрывается; общий рейтинг загружает всех игроков; закрытые комнаты остаются в памяти. Не исправлялись в этом этапе.
- Не уточнён состав колоды для выбора раздающего (сейчас 36 карт); перед изменением спросить владельца.
- Существовавшее изменение mobile/lib/main.dart (GARBA_ROOM для отладки) сохранено. Игровые правила и зависимости не менялись.
